# MarketTwin Web

The React and TypeScript frontend for MarketTwin.

This component will provide:

- Authentication
- Dashboard
- Product Blueprints
- Source uploads
- Knowledge review
- Skills
- Agent Blueprints
- Mission Templates
- Application Targets
- Test Plans
- Live Test Runs
- Human-assisted browser control
- Evidence viewer
- Reports
- Profile and settings

The complete Vite application will be generated in a later step.
