# MarketTwin Browser Runtime

This independently deployable component will contain:

- Official Playwright MCP
- Direct Playwright helpers
- Chromium
- BrowserContext isolation
- Accessibility snapshots
- Screenshots
- Playwright traces
- Console capture
- Network failure capture
- Domain restrictions
- Human-assisted authentication
- Xvfb
- x11vnc
- noVNC
- websockify

The browser runtime performs browser operations. Agent reasoning remains in the Execution Orchestrator.
